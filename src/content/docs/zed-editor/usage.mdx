## Getting Started with AgentLoop in Zed

Once installed and configured, AgentLoop provides powerful AI assistance directly within your Zed workflow. This guide covers the most effective patterns and techniques.

## Basic Workflows

### 1. Assistant Panel

The primary interface for interacting with AgentLoop:

**Opening the Assistant Panel:**
- **Keyboard**: `Cmd/Ctrl + Shift + A`
- **Command Palette**: `Cmd/Ctrl + Shift + P` → "Assistant: Toggle"
- **Menu**: View → Assistant Panel

**Basic Usage:**
1. Open the Assistant Panel
2. Type your question or request
3. Press `Enter` or `Cmd/Ctrl + Enter` to submit
4. Watch the streaming response
5. Apply suggested changes or ask follow-up questions

### 2. Inline Assistance

For quick, context-aware help without leaving the editor:

**Inline Assist:**
- **Keyboard**: `Cmd/Ctrl + K`
- Select code (optional) and press the shortcut
- Type your request in the inline prompt
- Press `Enter` to get contextual suggestions

**Selection-Based Assistance:**
```rust
// Select this function and press Cmd/Ctrl + K
fn complex_calculation(data: &[f64]) -> Result<f64, Error> {
    // Complex implementation here...
}

// Then ask: "optimize this function for better performance"
```

### 3. Context Commands

Special commands that control what context AgentLoop sees:

| Command | Purpose | Example |
|---------|---------|---------|
| `/context` | Show current context | View what files/info will be included |
| `/project` | Include project structure | Add file tree to context |
| `/git` | Include git status | Add branch, changes, recent commits |
| `/errors` | Include diagnostics | Add compiler errors and warnings |
| `/clear` | Clear conversation | Start fresh conversation |

```go
// Select function and ask: "generate comprehensive unit tests"

// Results in:
func TestCalculateTax(t *testing.T) {
    tests := []struct {
        name     string
        income   float64
        rate     float64
        expected float64
    }{
        {"normal case", 1000.0, 0.2, 200.0},

        {"negative income", -100.0, 0.2, 0.0},
        {"negative rate", 1000.0, -0.1, 0.0},

        })
    }
}
```

### Error Resolution

**Compiler Error Assistance:**
When you have compilation errors, AgentLoop automatically includes diagnostic context:

```rust

 --> src/main.rs:42:5
  |
42|     Ok(result)
  |     ^^^^^^^^^^ expected `Result<String, Error>`, found `Result<i32, Error>`
```

Ask: "How do I fix this type mismatch error?"
AgentLoop sees the error and surrounding code, providing specific solutions.

**Runtime Error Debugging:**

```typescript
// POST /api/users { name: string, email: string }
// Returns: { id: string, name: string, email: string, created_at: string }

interface CreateUserRequest {
  name: string;
  email: string;
}

interface User {
  id: string;
  name: string;
  email: string;
  created_at: string;
}

class UserAPI {
  async createUser(data: CreateUserRequest): Promise<User> {
    const response = await fetch('/api/users', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(data),
    });

      throw new Error(`Failed to create user: ${response.statusText}`);
    }
    
    return response.json();
  }
}
```

## Troubleshooting Common Issues

### Response Quality Issues

**Problem**: Generic or irrelevant responses
**Solution**: 
- Provide more specific context
- Use `/context` to check what AgentLoop sees
- Include relevant background information

**Problem**: Code doesn't match project style
**Solution**:
- Include style guide or linting configuration
- Reference existing code patterns
- Ask explicitly about style preferences

### Performance Issues

**Problem**: Slow responses
**Solution**:
- Reduce context with smaller selections
- Use `/clear` to reset conversation
- Check configuration limits

**Problem**: Context too large errors  
**Solution**:
- Select smaller code sections
- Use `excluded_patterns` in configuration
- Focus on specific files/functions

### Integration Issues

**Problem**: Context missing expected information
**Solution**:
- Verify file types are in `allowed_file_types`
- Check `excluded_patterns` configuration
- Use manual context commands
