## Installation

### Prerequisites

- **Rust 1.70+**: Install via [rustup](https://rustup.rs/)
- **AgentLoop Go Server**: Must be installed and running
- **Zed Editor**: Latest version with ACP support
- **Unix-like OS**: Linux, macOS, or WSL2 on Windows

### Add to Your Project

<Tabs>
<TabItem label="Cargo.toml">

```toml title="Cargo.toml" {7-8}
[dependencies]
# Core async runtime
tokio = { version = "1.0", features = ["full"] }

# AgentLoop client
agentloop-bridge = { git = "https://github.com/user/agentloop-rs", version = "0.1" }

# Optional: For Zed editor integration
agentloop-bridge = { git = "https://github.com/user/agentloop-rs", version = "0.1", features = ["zed-acp"] }
```

cargo build --release -p agentloop-bridge --features zed-acp

## Basic Configuration

### Default Configuration

The client uses sensible defaults that work with standard AgentLoop setups:

```rust title="src/main.rs"
use agentloop_bridge::{AgentLoopClient, ClientConfig};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    // Uses ~/.local/share/agentloop/agentloop.sock by default
    let config = ClientConfig::default();
    let mut client = AgentLoopClient::new(config);
    
    // Connect to server
    client.connect().await?;
    
    Ok(())
}
```

### Custom Configuration

For non-standard setups, customize the configuration:

```rust title="src/main.rs"
use agentloop_bridge::{AgentLoopClient, ClientConfig};
use std::{path::PathBuf, time::Duration};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let config = ClientConfig {
        socket_path: PathBuf::from("/custom/path/agentloop.sock"),
        request_timeout: Duration::from_secs(60), // Longer timeout
        max_retries: 5,                           // More retry attempts
        retry_delay: Duration::from_millis(2000), // Longer retry delay
        event_buffer_size: 2000,                  // Larger event buffer
    };
    
    let mut client = AgentLoopClient::new(config);
    client.connect().await?;
    
    Ok(())
}
```

## AgentLoop Go Server Setup

The Rust ACP bridge requires the **AgentLoop Go server** to be running. The bridge does not include any server functionality.

### Install & Run Go Server

```bash
# Install Go server from main AgentLoop repository
cd /path/to/agentloop
go build -o agentloop-server ./cmd/agentloop-server

# Start server (must be running before using Zed integration)
./agentloop-server
# Server listening on ~/.local/share/agentloop/agentloop.sock
```

### Server Configuration

```yaml title="~/.config/agentloop/agentloop.yaml"
server:
  socket_path: ~/.local/share/agentloop/agentloop.sock

pi:
  binary_path: pi
  provider: anthropic
  model: claude-sonnet-4-20250514

memory:
  profile_entries_limit: 100
  conversation_retention_days: 30

sessions:
  max_concurrent: 10
  max_per_user: 5
  timeout_seconds: 3600

# Security settings apply to all clients including Rust bridge
security:
  allowed_paths: ["~/dev", "~/projects"]
  injection_protection:
    enabled: true
```

<Aside type="caution">
  **Server Requirement**: The Rust bridge cannot function without the AgentLoop Go server running. Make sure `./agentloop-server` is running before attempting to use the Zed integration.
</Aside>

<Aside type="note">
  **Automatic Memory Management**: The AgentLoop Go server automatically handles all memory management, conversation logging, skill detection, and session persistence. The Rust bridge is purely a communication layer - no additional memory configuration is needed.
</Aside>

## Testing the Connection

### Health Check

```rust title="examples/health_check.rs"
use agentloop_bridge::{AgentLoopClient, ClientConfig};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mut client = AgentLoopClient::new(ClientConfig::default());
    
    // Connect and check health
    client.connect().await?;
    let health = client.health_check().await?;
    
    println!("Server health: {}", health);
    
    Ok(())
}
```

### Simple Task

```rust title="examples/simple_task.rs"
use agentloop_bridge::{AgentLoopClient, ClientConfig, AgentEvent};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mut client = AgentLoopClient::new(ClientConfig::default());
    client.connect().await?;
    
    // Start a simple task
    let session_id = client.start_task(
        "test_user",           // User ID
        "What is 2 + 2?",     // Task description  
        None,                 // Working directory
        "rust-example"        // Source identifier
    ).await?;
    
    println!("Started task: {}", session_id);
    
    // Listen for events
    let mut event_rx = client.take_event_receiver().unwrap();
    while let Some(event) = event_rx.recv().await {
        match event {
            AgentEvent::Text { content, .. } => {
                print!("{}", content); // Stream output
            }
            AgentEvent::Done { stats, .. } => {
                println!("\nTask completed: {} tool calls", stats.tool_calls);
                break;
            }
            AgentEvent::Error { message, .. } => {
                eprintln!("Error: {}", message);
                break;
            }
            _ => {} // Handle other events as needed
        }
    }
    
    Ok(())
}
```

## Common Issues

### Connection Refused

```
Error: Os { code: 111, kind: ConnectionRefused, message: "Connection refused" }
```

**Solutions:**
1. Ensure AgentLoop server is running
2. Check socket path in configuration
3. Verify socket permissions (should be 0700)

### Permission Denied

```
Error: Os { code: 13, kind: PermissionDenied, message: "Permission denied" }
```

**Solutions:**
1. Run client as same user as server
2. Check socket file permissions
3. Verify parent directory permissions

### Timeout Errors

```
Error: Timeout { message: "Request task.start timed out" }
```

**Solutions:**
1. Increase `request_timeout` in client config
2. Check server resource usage
3. Ensure pi binary is available and working

## Performance Tuning

### Event Buffer Size

For high-throughput applications, increase the event buffer:

```rust
let config = ClientConfig {
    event_buffer_size: 10_000, // Default is 1,000
    ..ClientConfig::default()
};
```

### Connection Pooling

For applications with multiple concurrent tasks, consider connection pooling:

```rust
use std::sync::Arc;
use tokio::sync::Mutex;

// Shared client for multiple tasks
let client = Arc::new(Mutex::new(AgentLoopClient::new(config)));

// Use in multiple async tasks
let client_clone = Arc::clone(&client);
tokio::spawn(async move {
    let mut client = client_clone.lock().await;
    client.start_task("user1", "task1", None, "app").await.unwrap();
});
```

<Aside type="caution">
  **Connection Sharing**: The client is not `Sync` by design. Each connection should be owned by a single task. For multi-client scenarios, create multiple `AgentLoopClient` instances rather than sharing one.
</Aside>
